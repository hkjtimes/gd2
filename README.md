# Geometry Dash AI — нейросеть, играющая в случайные уровни

Нейросеть, написанная **полностью с нуля на numpy** (без PyTorch/TensorFlow:
прямой и обратный проход, Adam и PPO реализованы вручную), которая учится
проходить процедурно генерируемые уровни в стиле Geometry Dash.

Агент **не заучивает уровень** — каждый эпизод генерируется новый случайный
уровень, поэтому сеть вынуждена научиться *читать* карту перед собой и
адаптироваться:

* **7 режимов игрока** — куб, корабль (ракета), шар, НЛО, волна, робот, паук —
  с разной физикой (прыжок, полёт на тяге, переворот гравитации, телепорт
  на противоположную поверхность и т.д.);
* **порталы скорости** 0.5x / 1x / 2x / 3x / 4x;
* **порталы размера** (мини/обычный — меняется хитбокс и высота прыжка);
* **порталы гравитации** (движение «вверх ногами»);
* **декорации** — не влияющие на игру объекты, в том числе плотные «колонны»,
  похожие на препятствия. Они подаются сети отдельным каналом наблюдения,
  и сеть должна научиться их игнорировать.

## Как это устроено

```
gd_ai/
├── env/
│   ├── constants.py   # тайлы, режимы, физические константы
│   ├── level_gen.py   # процедурный генератор уровней (+декор, +порталы)
│   └── env.py         # физика всех режимов, столкновения, наблюдения, ASCII-рендер
├── nn/
│   ├── layers.py      # Dense/ReLU/Tanh + ручной backprop + Adam (чистый numpy)
│   └── model.py       # актор-критик: общий ствол MLP, головы policy и value
├── agent/
│   └── ppo.py         # PPO с GAE: градиенты выведены аналитически
├── train.py           # обучение: curriculum + доменная рандомизация
├── evaluate.py        # метрики на пачке новых случайных уровней
└── play.py            # смотреть игру агента в терминале (ASCII)
```

**Наблюдение** (вход сети, 1456 чисел): локальное окно 24×12 тайлов вокруг
игрока в 5 каналах (блоки / шипы / декор / маска порталов / код портала) +
вектор состояния из 16 чисел: позиция и скорость по вертикали, направление
гравитации, опора под ногами, one-hot текущего режима (7), текущая скорость,
флаг мини-размера и т.п. Благодаря этому одна и та же сеть знает, в каком
режиме и с какими модификаторами она сейчас летит, и заранее видит порталы.

**Действие**: одна кнопка, как в GD — на каждом тике «зажата» или «отпущена».

**Обучение**: PPO (clipped surrogate + GAE + entropy bonus). Награда —
продвижение вправо, штраф за смерть, бонус за финиш. Сложность растёт
автоматически (curriculum): когда агент стабильно проходит >70% уровня,
генератор усложняет уровни и включает новые типы порталов.

## Запуск

```bash
pip install numpy          # единственная зависимость (pytest — для тестов)

# обучение с нуля (чекпоинт сохраняется каждые 25 итераций)
python -m gd_ai.train --updates 2000 --envs 16 --lr 1e-3 --out checkpoints/agent.npz

# продолжить обучение
python -m gd_ai.train --resume checkpoints/agent.npz --start-difficulty 0.3 ...

# оценка на 50 новых случайных уровнях
python -m gd_ai.evaluate --model checkpoints/agent.npz --difficulty 0.5 --episodes 50

# посмотреть, как агент играет (ASCII-анимация в терминале)
python -m gd_ai.play --model checkpoints/agent.npz --difficulty 0.4

# посмотреть саму среду со случайным агентом
python -m gd_ai.play --random
```

## Тесты

```bash
python -m pytest tests/ -q
```

* `test_nn_gradcheck.py` — все ручные градиенты сверены с численным
  дифференцированием (главная гарантия корректности backprop);
* `test_env.py` — физика каждого режима, все типы порталов, «декор не убивает»,
  проходимость сгенерированных уровней;
* `test_ppo_smoke.py` — короткое обучение проходит и улучшает политику.

## Упрощения относительно настоящей GD

Физика приближена по пропорциям (высота прыжка ~2 тайла, скорости в
соотношении 0.8:1:1.25:1.5:1.85), но не является точной копией движка GD.
Нет орбов, пэдов и даш-сфер; пол и потолок мира не убивают ни в одном режиме.
Эти механики добавляются в `env.py` по той же схеме, что и существующие.
